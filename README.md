# findward

Standalone public marketing website and custom Google Calendar consultation booking. PHP 8.4.1+, Composer 2, Node 20.19+ or 22.12+. No database, account/admin area, queue worker, Redis or server Node daemon.

## Local preparation

Run from this directory using your normal, working PHP command:

    composer install
    npm ci
    npm run build

No setup script or migration is required. For a local server, privately create your own .env from .env.example and generate a new APP_KEY using php artisan key:generate. This is an owner step; credentials and keys have not been configured by the extraction. Keep booking/provider gates false for local previews.

    php artisan serve --host=127.0.0.1 --port=8000

The public UI can also be checked against the built bundle without PHP or Google:

    npm run check
    npm run test:browser

PHP fixture tests are provided but deferred as requested:

    php vendor/bin/phpunit

Production build includes homepage HTML generated from the same React component, so no permanent Node SSR service is required. Runtime page data remains generated by Laravel; React hydrates the prerendered homepage. Dates and slot/confirmation labels use the visitor's automatic timezone, while owner policy stays Mon-Fri09-17 Europe/Skopje,20minMeet.

See docs/HOSTINGER.md for the private application/public_html arrangement and separate activation steps. See docs/BOOKING.md for booking behavior and recovery limits.
